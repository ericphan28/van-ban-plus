```tsx
// Tệp nối bộ định tuyến — bản Next.js (mặc định). Thành phần của kit KHÔNG import next/* trực tiếp, chỉ import tệp này.
// Dự án React Router (Vite): node cai.mjs <project> --ghi --dieu-huong react-router → chép bien-the/react-router thay tệp này.
import NextLink from "next/link";
import { usePathname as usePathnameNext, useRouter } from "next/navigation";
import type { AnchorHTMLAttributes, ReactNode } from "react";

export type ThuocTinhLink = Omit<AnchorHTMLAttributes<HTMLAnchorElement>, "href"> & { href: string; children?: ReactNode };

/** Bản React Router phát sự kiện này khi refresh(); bản Next không dùng (router.refresh dựng lại phía máy chủ). */
export const SU_KIEN_LAM_MOI = "osk-lam-moi";

export function Link({ href, ...p }: ThuocTinhLink) {
  return <NextLink href={href} {...p} />;
}

export function usePathname(): string | null {
  return usePathnameNext();
}

export function useDieuHuong(): { push: (href: string) => void; refresh: () => void } {
  const r = useRouter();
  return { push: (href) => r.push(href), refresh: () => r.refresh() };
}
```

`bien-the/react-router/dieu-huong.tsx`:

```tsx
// Tệp nối bộ định tuyến — bản React Router 7 (SPA, Vite). cai.mjs chép tệp này thành src/os-kit/dieu-huong.tsx khi
// cài với --dieu-huong react-router. Không có máy chủ dựng lại trang: refresh() phát SU_KIEN_LAM_MOI trên window để
// project tự đọc lại cookie cài đặt giao diện.
import { Link as LinkRR, useLocation, useNavigate } from "react-router";
import type { AnchorHTMLAttributes, ReactNode } from "react";

export type ThuocTinhLink = Omit<AnchorHTMLAttributes<HTMLAnchorElement>, "href"> & { href: string; children?: ReactNode };

export const SU_KIEN_LAM_MOI = "osk-lam-moi";

const NGOAI = /^(?:[a-z][a-z0-9+.-]*:|\/\/)/i; // https:, mailto:, tel:, //host

export function Link({ href, ...p }: ThuocTinhLink) {
  if (NGOAI.test(href)) return <a href={href} {...p} />;
  return <LinkRR to={href} {...p} />;
}

export function usePathname(): string | null {
  return useLocation().pathname;
}

export function useDieuHuong(): { push: (href: string) => void; refresh: () => void } {
  const di = useNavigate();
  return {
    push: (href) => (NGOAI.test(href) ? window.location.assign(href) : void di(href)),
    refresh: () => window.dispatchEvent(new Event(SU_KIEN_LAM_MOI)),
  };
}
```

```ts
// Lớp gọi API DUY NHẤT của web (hợp đồng mục 6). Access token chỉ ở bộ nhớ; token làm mới là cookie HttpOnly
// vbp_lam_moi do API đặt (Path=/api/v2/phien) → mọi yêu cầu gửi credentials: "include".
import type { PhienTraVe } from "./loai";

export class LoiApi extends Error {
  constructor(public http: number, public code: string, message: string, public data?: Record<string, unknown>) {
    super(message);
    this.name = "LoiApi";
  }
}
export type KetQua<T> = { data: T; code?: string; message: string };
type ThanTraVe = { success?: boolean; message?: string; code?: string; data?: unknown };

export type CauHinhKhach = {
  goc: string;
  fetch: typeof fetch;
  cho: (ms: number) => Promise<void>;
  /** khóa giữa các tab (navigator.locks); undefined = không khóa */
  khoa?: <T>(ten: string, fn: () => Promise<T>) => Promise<T>;
  bayGio: () => number;
};

const khoaTrinhDuyet: CauHinhKhach["khoa"] =
  typeof navigator !== "undefined" && "locks" in navigator
    ? (ten, fn) => navigator.locks.request(ten, fn)
    : undefined;

let ch: CauHinhKhach = {
  goc: (import.meta.env.VITE_API_GOC || "https://vanbanplus.giakiemso.com").replace(/\/$/, ""),
  fetch: (...a) => fetch(...a),
  cho: (ms) => new Promise((r) => setTimeout(r, ms)),
  khoa: khoaTrinhDuyet,
  bayGio: () => Date.now(),
};
export function caiKhach(c: Partial<CauHinhKhach>) { ch = { ...ch, ...c }; }

let token: string | null = null;
let hetHanLuc = 0;
const nguoiNghe = new Set<(p: PhienTraVe | null) => void>();

export function datPhien(p: PhienTraVe | null) {
  token = p?.access_token ?? null;
  hetHanLuc = p ? ch.bayGio() + p.het_han_giay * 1000 : 0;
  for (const f of nguoiNghe) f(p);
}
export const coPhien = () => token !== null;
export function khiDoiPhien(fn: (p: PhienTraVe | null) => void) {
  nguoiNghe.add(fn);
  return () => { nguoiNghe.delete(fn); };
}

async function docThan(r: Response): Promise<ThanTraVe> {
  try { return (await r.json()) as ThanTraVe; }
  catch { return { success: false, message: "Máy chủ trả lời không đọc được. Thử lại sau." }; }
}

async function guiTho(duong: string, phuongThuc: string, than: unknown, bearer: string | null) {
  const dau: Record<string, string> = {};
  if (than !== undefined) dau["Content-Type"] = "application/json";
  if (bearer) dau.Authorization = `Bearer ${bearer}`;
  let r: Response;
  try {
    r = await ch.fetch(ch.goc + duong, {
      method: phuongThuc, headers: dau, credentials: "include",
      body: than === undefined ? undefined : JSON.stringify(than),
    });
  } catch {
    throw new LoiApi(0, "MAT_MANG", "Không kết nối được máy chủ. Kiểm tra mạng rồi thử lại.");
  }
  return { r, j: await docThan(r) };
}

let dangLamMoi: Promise<PhienTraVe | null> | null = null;

async function lamMoiMotLan(): Promise<PhienTraVe | null> {
  for (let lan = 0; lan < 2; lan++) {
    const { r, j } = await guiTho("/api/v2/phien/lam-moi", "POST", {}, null);
    if (r.ok && j.success && j.data) {
      const p = j.data as PhienTraVe;
      datPhien(p);
      return p;
    }
    if (j.code === "LAM_MOI_TRUNG" && lan === 0) { await ch.cho(1000); continue; }
    if (r.status >= 500 && r.status !== 503) throw new LoiApi(r.status, j.code ?? "LOI_MAY_CHU", j.message ?? "Lỗi máy chủ.");
    break;
  }
  datPhien(null);
  return null;
}

/** Làm mới phiên. Một lần trong tab (gộp yêu cầu song song) và tuần tự giữa các tab (navigator.locks). */
export function lamMoi(): Promise<PhienTraVe | null> {
  if (!dangLamMoi) {
    const chay = () => lamMoiMotLan();
    dangLamMoi = (ch.khoa ? ch.khoa("vbp-lam-moi", chay) : chay()).finally(() => { dangLamMoi = null; });
  }
  return dangLamMoi;
}

export async function goi<T>(
  duong: string,
  tuy: { phuongThuc?: "GET" | "POST" | "PATCH" | "DELETE"; than?: unknown } = {},
): Promise<KetQua<T>> {
  const pt = tuy.phuongThuc ?? "GET";
  if (token && hetHanLuc - ch.bayGio() < 30_000) await lamMoi();
  let bearer = token;
  let { r, j } = await guiTho(duong, pt, tuy.than, bearer);
  if (r.status === 401 && bearer) {
    const p = await lamMoi();
    if (!p) throw new LoiApi(401, "PHIEN_THU_HOI", "Phiên đăng nhập đã kết thúc. Đăng nhập lại.");
    bearer = p.access_token;
    ({ r, j } = await guiTho(duong, pt, tuy.than, bearer));
  }
  if (!r.ok || j.success === false) {
    throw new LoiApi(r.status, j.code ?? (r.status === 401 ? "CHUA_DANG_NHAP" : "LOI_MAY_CHU"),
      j.message || "Có lỗi. Thử lại sau.", j.data as Record<string, unknown> | undefined);
  }
  return { data: j.data as T, code: j.code, message: j.message ?? "" };
}
```

```tsx
export type TrangThaiPhien = "dang-tai" | "mat-mang" | "khach" | "vao";
type GiaTri = {
  trangThai: TrangThaiPhien; nguoiDung: NguoiDung | null;
  vaoPhien(p: PhienTraVe): void; capNhatNguoiDung(n: NguoiDung): void; dangXuat(): Promise<void>; thuLai(): void;
};
const Ctx = createContext<GiaTri | null>(null);
const KENH = "vbp-phien";

export function PhienProvider({ children }: { children: ReactNode }) {
  const [trangThai, setTrangThai] = useState<TrangThaiPhien>("dang-tai");
  const [nguoiDung, setNguoiDung] = useState<NguoiDung | null>(null);
  const [lan, setLan] = useState(0);

  useEffect(() => khiDoiPhien((p) => {
    setNguoiDung(p?.nguoi_dung ?? null);
    setTrangThai(p ? "vao" : "khach");
  }), []);

  useEffect(() => {
    let huy = false;
    setTrangThai("dang-tai");
    lamMoi().catch(() => { if (!huy) setTrangThai("mat-mang"); });
    return () => { huy = true; };
  }, [lan]);

  // đồng bộ giữa các tab: tab khác đăng xuất → tab này cũng ra; tab khác đăng nhập → tab đang ở màn khách làm mới
  useEffect(() => {
    if (typeof BroadcastChannel === "undefined") return;
    const k = new BroadcastChannel(KENH);
    k.onmessage = (e) => {
      if (e.data === "dang-xuat") datPhien(null);
      if (e.data === "dang-nhap") void lamMoi().catch(() => {});
    };
    return () => k.close();
  }, []);
  const bao = (tin: string) => { if (typeof BroadcastChannel !== "undefined") { const k = new BroadcastChannel(KENH); k.postMessage(tin); k.close(); } };

  const vaoPhien = useCallback((p: PhienTraVe) => { datPhien(p); bao("dang-nhap"); }, []);
  const dangXuat = useCallback(async () => { await api.dangXuat().catch(() => {}); bao("dang-xuat"); }, []);
  const gt = useMemo<GiaTri>(() => ({
    trangThai, nguoiDung, vaoPhien, dangXuat,
    capNhatNguoiDung: (n) => setNguoiDung(n),
    thuLai: () => setLan((x) => x + 1),
  }), [trangThai, nguoiDung, vaoPhien, dangXuat]);
  return <Ctx.Provider value={gt}>{children}</Ctx.Provider>;
}

export function usePhien(): GiaTri {
  const g = useContext(Ctx);
  if (!g) throw new Error("usePhien cần PhienProvider");
  return g;
}
```

```ts
const NGAY = new Intl.DateTimeFormat("vi-VN", { timeZone: "Asia/Ho_Chi_Minh", day: "2-digit", month: "2-digit", year: "numeric" });
const SO = new Intl.NumberFormat("vi-VN", { maximumFractionDigits: 1 });

export function dinhDangByte(b: number): string {
  const don = ["B", "KB", "MB", "GB", "TB"];
  let i = 0; let x = b;
  while (x >= 1024 && i < don.length - 1) { x /= 1024; i++; }
  return `${SO.format(x)} ${don[i]}`;
}
export const dinhDangNgay = (iso: string) => NGAY.format(new Date(iso));
export function truocDay(iso: string, bayGio = Date.now()): string {
  const giay = (bayGio - Date.parse(iso)) / 1000;
  if (giay < 60) return "vừa xong";
  if (giay < 3600) return `${Math.floor(giay / 60)} phút trước`;
  if (giay < 86400) return `${Math.floor(giay / 3600)} giờ trước`;
  if (giay < 7 * 86400) return `${Math.floor(giay / 86400)} ngày trước`;
  return dinhDangNgay(iso);
}
export function conLai(iso: string | null, bayGio = Date.now()): number | null {
  return iso ? Math.ceil((Date.parse(iso) - bayGio) / 86400000) : null;
}
export const dinhDangSo = (n: number) => new Intl.NumberFormat("vi-VN").format(n);
```

```ts
import { LoiApi } from "@/api/khach";

const GIO = new Intl.DateTimeFormat("vi-VN", { timeZone: "Asia/Ho_Chi_Minh", hour: "2-digit", minute: "2-digit" });

export function thongBaoLoi(e: unknown): string {
  if (!(e instanceof LoiApi)) return "Có lỗi không mong muốn. Thử lại sau.";
  if (e.code === "TAI_KHOAN_KHOA" && typeof e.data?.mo_luc === "string")
    return `Sai mật khẩu nhiều lần. Tài khoản tạm khóa tới ${GIO.format(new Date(e.data.mo_luc))}.`;
  if (e.code === "QUA_NHIEU_YEU_CAU") {
    const g = Number(e.data?.thu_lai_sau_giay ?? 60);
    return `Thao tác quá nhiều lần. Thử lại sau ${g < 120 ? `${g} giây` : `${Math.ceil(g / 60)} phút`}.`;
  }
  if (e.code === "CHUA_CAU_HINH") return "Chức năng này chưa được bật trên máy chủ. Dùng cách đăng nhập khác.";
  return e.message || "Có lỗi. Thử lại sau.";
}
```

```tsx
import { useId, useState, type InputHTMLAttributes, type ReactNode } from "react";
import { OskNet } from "@/os-kit/icons/OskIcon";

type ThuocTinhO = InputHTMLAttributes<HTMLInputElement> & { nhan: string; goiY?: ReactNode; loi?: string };

export function OChu({ nhan, goiY, loi, id, ...p }: ThuocTinhO) {
  const tuSinh = useId(); const ma = id ?? tuSinh;
  return (
    <div className="o">
      <label htmlFor={ma}>{nhan}</label>
      <input id={ma} aria-invalid={loi ? true : undefined} aria-describedby={goiY || loi ? `${ma}-g` : undefined} {...p} />
      {(loi || goiY) && <small id={`${ma}-g`} className={loi ? "o__loi" : "o__goi-y"}>{loi ?? goiY}</small>}
    </div>
  );
}

export function doManh(mk: string): 0 | 1 | 2 | 3 {
  if (mk.length < 8) return 0;
  const loai = [/[a-z]/, /[A-Z]/, /\d/, /[^\w\s]/].filter((r) => r.test(mk)).length;
  return mk.length >= 12 && loai >= 3 ? 3 : loai >= 2 ? 2 : 1;
}

export function OMatKhau({ hienDoManh, ...p }: ThuocTinhO & { hienDoManh?: boolean }) {
  const [hien, setHien] = useState(false);
  const dm = hienDoManh ? doManh(String(p.value ?? "")) : null;
  return (
    <div className="o-mat-khau">
      <OChu {...p} type={hien ? "text" : "password"} />
      <button type="button" className="o-mat-khau__nut" onClick={() => setHien(!hien)} aria-label={hien ? "Ẩn mật khẩu" : "Hiện mật khẩu"} aria-pressed={hien}>
        <OskNet ma="xem" kich={18} />
      </button>
      {dm !== null && String(p.value ?? "").length > 0 && (
        <div className={`do-manh do-manh--${dm}`} aria-live="polite">
          <span /><span /><span />
          <small>{["Tối thiểu 8 ký tự", "Tạm được", "Khá", "Mạnh"][dm]}</small>
        </div>
      )}
    </div>
  );
}

export function OMa({ value, onChange, soKyTu = 6, tuDongGui, nhan, chuCai = false }:
  { value: string; onChange(v: string): void; soKyTu?: number; tuDongGui?(v: string): void; nhan: string; chuCai?: boolean }) {
  const loc = (s: string) => (chuCai ? s.replace(/[^0-9a-zA-Z-]/g, "") : s.replace(/\D/g, "")).slice(0, chuCai ? 20 : soKyTu);
  return (
    <OChu nhan={nhan} className="o-ma" value={value} inputMode={chuCai ? "text" : "numeric"} autoComplete="one-time-code"
      enterKeyHint="done" maxLength={chuCai ? 20 : soKyTu}
      onChange={(e) => { const v = loc(e.target.value); onChange(v); if (!chuCai && v.length === soKyTu) tuDongGui?.(v); }} />
```

```js
import { chromium } from "playwright";
import { mkdirSync } from "node:fs";
import { spawn } from "node:child_process";
import { gắnApiGia } from "./api-gia.mjs";

const GOC = "http://localhost:4173";
const RA = ".tam/chup";
mkdirSync(RA, { recursive: true });
const may = spawn("npx", ["vite", "preview", "--port", "4173", "--strictPort"], { shell: true, stdio: "ignore" });
await new Promise((r) => setTimeout(r, 2500));

const MAN = [
  { ten: "dang-nhap", kb: "khach", duong: "/dang-nhap" },
  { ten: "dang-nhap-ma", kb: "khach", duong: "/dang-nhap?cach=ma" },
  { ten: "dang-ky", kb: "khach", duong: "/dang-ky" },
  { ten: "quen-mat-khau", kb: "khach", duong: "/quen-mat-khau" },
  { ten: "trang-chu", kb: "vao", duong: "/" },
  { ten: "tai-khoan", kb: "vao", duong: "/tai-khoan" },
  { ten: "tai-khoan-chi-doc", kb: "chi-doc", duong: "/tai-khoan" },
  { ten: "bao-mat", kb: "vao", duong: "/tai-khoan/bao-mat" },
  { ten: "bat-2-lop", kb: "vao", duong: "/tai-khoan/bao-mat", bam: "Bật xác thực 2 lớp" },
  { ten: "thiet-bi", kb: "vao", duong: "/tai-khoan/thiet-bi" },
  { ten: "cai-dat", kb: "vao", duong: "/cai-dat" },
  { ten: "sap-co", kb: "vao", duong: "/sap-co/van-ban" },
  { ten: "khong-thay", kb: "vao", duong: "/khong-co-trang-nay" },
];
const KHUNG = [
  { rong: 1440, cao: 900, tl: 1, dt: false },
  { rong: 390, cao: 844, tl: 3, dt: true },
];
const TOI = new Set(["dang-nhap", "trang-chu", "tai-khoan"]);

const b = await chromium.launch();
try {
  for (const k of KHUNG) for (const m of MAN) for (const toi of [false, true]) {
    if (toi && !TOI.has(m.ten)) continue;
    const ctx = await b.newContext({ viewport: { width: k.rong, height: k.cao }, deviceScaleFactor: k.tl, isMobile: k.dt,
      hasTouch: k.dt, colorScheme: toi ? "dark" : "light", locale: "vi-VN", timezoneId: "Asia/Ho_Chi_Minh" });
    const p = await ctx.newPage();
    await gắnApiGia(p, m.kb);
    await p.goto(GOC + m.duong, { waitUntil: "networkidle" });
    if (m.bam) { await p.getByRole("button", { name: m.bam }).click(); await p.waitForTimeout(400); }
    await p.waitForTimeout(300);
    await p.screenshot({ path: `${RA}/${m.ten}-${k.rong}${toi ? "-toi" : ""}.png`, fullPage: true });
    await ctx.close();
  }
} finally {
  await b.close();
  may.kill();
}
console.log(`Đã chụp vào ${RA}`);
```

Bản build chụp cần `VITE_API_GOC` mặc định (prod) — `page.route` chặn nên không gọi thật. Trên Windows `may.kill()` có
thể không dừng tiến trình con của `npx`; nếu cổng 4173 còn bận ở lần sau thì dùng `taskkill /PID <pid> /T /F` trong
`finally` (`process.platform === "win32"`).
